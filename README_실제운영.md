## 설치 (한 번만)

### 1. 구글시트 + Apps Script
1. 구글시트 새로 만들기 → 이름 "매화 RAS 데이터"
2. 확장 프로그램 → Apps Script → 기존 코드 삭제 → `AppsScript_code.gs` 붙여넣기 → 저장
3. 배포 → 새 배포 → 웹 앱 → 실행 계정 "나", 액세스 "모든 사용자" → 배포
4. 나오는 웹 앱 URL(`https://script.google.com/macros/s/..../exec`) 복사

> 코드를 고쳐 다시 배포할 때는 **배포 → 배포 관리 → 연필 → 버전 "새 버전" → 배포**. 이걸 빠뜨리면 옛 코드가 계속 돕니다.

### 2. 화면에 URL 넣기 (기기마다 한 번)
각 실연동 화면 상단 배너 "설정"에 같은 URL과 열쇠말(maehwa-2027) 입력 → "✓ 연결됨".
같은 브라우저면 한 번만 넣어도 다른 화면이 공유합니다.

### 3. 웹에 올리기 (GitHub Pages)
이 폴더의 파일 전부를 저장소에 업로드 → Settings → Pages → Branch main → 저장.
주소: `https://아이디.github.io/저장소이름/` (index.html이 자동으로 열림)

## 주의 (실제 운영 전 반드시)

- **학급명 자동변환**: "3-1"이 날짜로 바뀌지 않도록 최신 `AppsScript_code.gs`(텍스트 고정 포함)를 써야 합니다.
- **AI 키 보안**: AI 화면은 키를 브라우저에 넣습니다. 공개 사이트에 키를 넣으면 도용될 수 있으니, 상시 운영에는 키를 숨기는 **중계 서버**가 필요합니다. 교육청 정보 담당과 상의하세요.
- **개인정보**: 학생 개인 식별정보는 수집하지 않는 설계입니다. 시트 공유는 교직원으로 제한하고, 원자료는 대회 규정(1년 이상) 및 교육청 지침에 따라 보관·관리하세요.
- **학생 대면 AI**(별이 사서·어린이 경영회의): 미성년자 약관 문제로 실제 운영 시 교사 매개 방식 권장.
